# Phase 6 final report: advanced model improvement for four-class LVEF

**Scope:** Phase 6 (pre-registered `PHASE6_PLAN.md`) plus its two controlled sub-studies, Phase 6A
(`../phase_6a_normal_mild_lstm/PHASE6A_FINAL_REPORT.md`: Normal/Mild boundary, Normal-270, standalone LSTM) and
Phase 6B (`../phase_6b_threshold_sampling_lstm/PHASE6B_FINAL_REPORT.md`: EF thresholds, Normal training sizes, LSTM /
CNN-LSTM / fusion; addendum `ADDENDUM_LABEL_EXPERIMENTS.md`).

**Data and protocol:** development-set CV only (837 ECGs / 794 patient keys; patient-grouped 5-fold × 3 repeats,
`phase_2/configs/folds_D.csv`). The 210-ECG locked test was never loaded, predicted, scored or inspected; no locked-test
PDF was run through any model.

Tables: `results/phase6_all_models.csv`, `results/phase6_comparisons.csv`, `results/phase6_selection.json`,
`results/stage1_screen.*`; plot `plots/phase6_stage1_screen.png`; claims `PHASE6_CLAIMS_REGISTER.md` (P6-1…P6-16).

## Answers to the Phase 6 questions

### 1. Best admissible, eligible development-CV model
Unchanged from Phase 5: **C3** (`P5D-E5-vote-prior-protected-v1`), the equal-weight vote of MLP fusion (header ‖
ECGFounder), ECGFounder linear (distance-CE) and header + clinical LR, with the nested class-prior rule.

- **Accuracy 0.561** (corrected 95 % CI **0.520–0.603**); balanced accuracy 0.456; macro-F1 0.448; QWK 0.571.
- Regenerated byte-identically in the cloud and within 0.005 on the owner's laptop.

| Class | Precision | Recall | F1 |
|---|---|---|---|
| Normal | 0.710 | 0.845 | 0.772 |
| Mild | 0.297 | 0.177 | 0.221 |
| Moderate | 0.455 | 0.460 | 0.457 |
| Severe | 0.344 | 0.344 | 0.343 |

Confusion matrix (mean over repeats; rows = label, columns = prediction N / Mi / Mo / S):
Normal 324 / 35 / 15 / 9; Mild 79 / 33 / 52 / 21; Moderate 38 / 27 / 81 / 31; Severe 15 / 14 / 30 / 31.

### 2. Genuine improvement over C1, C2 or C3?
**No.** None of the Phase 6, 6A or 6B candidates meets the criterion (Holm p < 0.05, same sign in all repeats,
admissible).
- **Phase 6:** no candidate passed the pre-registered Stage-1 screen (EF r ≥ 0.69, or macro-F1 ≥ 0.465 with all recalls
  ≥ 0.15), so Stage 2 and E were not run (P6-15).
- **6A / 6B:** the only Holm-significant results are **inferiority** of the standalone LSTMs (accuracy −0.09 vs C3).
  - Fusions with the LSTM are indistinguishable from C1 / C3 (e.g. F4 vs C3 −0.002).
  - The highest admissible figure, C3 trained on T55 labels at 0.569 on the original labels, is +0.007 over ORIG
    (Holm p 1.00).

### 3. EF correlation and the error budget
- The best representation remains the **frozen ECGFounder embedding**: EF r **0.659** seed-combined (R0), 0.65 per
  seed.
- Fine-tuning (A1 / A2: 0.650), ECG-FM (0.609), ECGFounder + ECG-FM (0.636) and the 2.5-s lead II input (0.647) do not
  improve it.
- **Error budget:** 60 % four-class accuracy needs r ≈ 0.82 and 65 % needs r ≈ 0.87; 80 % would need r ≈ 0.975 (6A).
  The models stay at r ≈ 0.66, so neither 60 % nor 65 % is attainable from this ECG information.
- The label ceiling (perfect EF) is 93.4 %.

### 4. Failed experiments and why
| Experiment | Result | Reason |
|---|---|---|
| A1 / A2 ECGFounder fine-tuning (stage 6; 5–6) | r 0.650 vs 0.652 (frozen) | early stopping selects epochs 4–15; with ~535 training ECGs per fold the backbone overfits before adding EF information |
| B ECG-FM (MIT); ECGFounder + ECG-FM | r 0.609 / 0.636 vs 0.638 | a second foundation encoder carries the same or less EF information |
| HuBERT-ECG, ST-MEM | not run | CC-BY-NC licences; owner decision pending |
| ECG-JEPA, MERL | not run | weights on Google Drive, blocked by the network policy |
| C (extra ECGs) | not run | no extra PDFs or waveforms exist |
| D1 digitisation quality | no effect | EF error unrelated to quality flags (ρ −0.04) |
| D2 10-s lead II strip | no added EF information | r 0.647 without vs 0.638 with the full strip |
| 6A / 6B standalone LSTM, CNN-LSTM | accuracy 0.47–0.50 | printout waveforms (2.5 s per lead) give a sequence model far less than the pretrained embedding |
| 6A / 6B fusions with the LSTM | 0.540–0.559 | no complementary information (adding LSTM-sel to the vote lowers macro-F1 in all repeats) |
| Normal training size (307 → 300 / 270 / 240 / 200; 270 by expansion) | −0.010 to +0.000 | prior shift only: Mild recall up (0.178 → 0.220), Normal recall down; discrimination unchanged |
| T50 / T55 thresholds | definition effect only | T50 raises scores on its own labels by relabelling 27 hard Mild cases; training on them adds nothing and lowers Mild recall |
| XUNC, BRES, VERB (removing / resolving borderline cases) | no gain on the original labels | Mild detection falls below the admissibility floor |
| VER (15 labels corrected to a high-confidence echo) | +0.4 points (0.565) | label noise explains < 0.5 points |

### 5. Name-pair sensitivity
Merging the 15 within-development near-identical name pairs (794 → 779 groups) and regenerating the folds changes
accuracy by −0.002 (MLP fusion), −0.010 (C1) and −0.008 (C3), within the repeat-to-repeat SD (P6-16). The estimates
may be up to about 1 point optimistic. The **11 development / test pairs and 3 test pairs remain unresolved**.

### 6. Ready for a one-time locked-test evaluation?
**Not yet.** No model is a genuine improvement over C3, so no new model is proposed for freezing. If the owner wants a
one-time locked-test evaluation, the defensible pre-registered shortlist is unchanged:
- **C3**, the selected model: frozen as `P5D-E5-vote-prior-protected-v1` with Phase 2 folds, members and the nested
  prior rule fitted on the full development set;
- **C1** (better balanced);
- **C2** (accuracy reference).

**Prerequisites:**
1. the owner resolves the 11 name pairs that straddle development and test (and the 3 within test);
2. the owner gives explicit written authorisation;
3. the test set is reported as previously exposed (Phase 1).

No locked-test step has been run.

### 7. Recommended next steps (ranked by expected value)
1. **Verified ECG–echo links** (medical record number / encounter ID, same-day echoes) for existing and new patients;
   this removes the fuzzy name matching.
2. **More abnormal-EF ECGs, especially Mild** (hundreds more, from new years or sites).
3. **Better EF labels:** biplane Simpson EF instead of Teichholz; repeat or double reads for borderline cases. The
   blinded manual review worklist prepared on the laptop is the immediate, cheaper version.
4. **Clinical covariates** (NT-proBNP, prior MI / heart failure, medications), if available, as additional inputs.
5. **Digital 10-s 12-lead ECGs** (XML / DICOM) instead of PDF printouts (small expected gain; D2).
6. **An independent temporal or external validation cohort** before any performance claim.
7. **Not recommended:** further architecture or decision-rule tuning on the same 837 ECGs; Phases 4–6 show the ceiling
   is the information in the inputs and the labels (≈ 0.55–0.57).
